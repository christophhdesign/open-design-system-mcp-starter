# Acme Elements (example)

This is a small, entirely fictional web-component design system, shipped only so the starter
runs end to end on a fresh clone with no setup. It is not a real product and does not model any
real design system.

Replace this directory (and `ds.config.json`) with your own system: point `catalog` at your
real `custom-elements.json`, react-docgen source, or pre-built catalog JSON, point `tokens` at
your real token files, and run `npx tsx src/cli.ts extract`.
